Generated by `npm run build:prices-to-confirm`. Do not edit by hand.

because the only price we have for it is Foodpanda's. Foodpanda prices carry
that channel's markup, so they are not pickup prices. Each row needs one
number from the owner, after which it is a price edit and a flip to active.

listing, captured 2026-09-07. A 15% vendor promo was masking the displayed
